# MilitaryVibeX Downloader

Private Windows automation for downloading authorized videos listed in the prepared Google Sheet.

## How to use

1. Double-click **Start MilitaryVibeX Downloader.cmd**.
2. Choose the download folder.
3. Choose how many videos to process in this run.
4. Confirm that you own the videos or have permission to reuse them.
5. Click **Start**.

The app saves completed links in `progress.json`. If you pause or close the app, the next run resumes without downloading completed videos again.

The Google Sheet link and the 1080p quality setting are already filled in.
